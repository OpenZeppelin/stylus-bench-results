= ERC-20 Flash Mint

Extension of xref:erc20.adoc[ERC-20] that provides flash loan support at the token level.

IMPORTANT: The default `flash_loan` helper does not account for the cap from the `Capped` extension. If the token combines flash minting with `Capped`, use the cap-aware helpers for both lender methods. Otherwise a borrower can observe a temporary `totalSupply` above the configured cap during its callback.

== Reentrant callbacks

Stylus SDK 0.10.10 rejects reentrant entrypoints by default. Borrower callbacks often read or call the lender token while a loan is active, so contracts using this extension should enable the library's `reentrant` Cargo feature:

[source,toml]
----
[dependencies]
openzeppelin-stylus = { version = "0.4", features = ["reentrant"] }
----

The feature allows callbacks to reenter the contract. Review callback paths for reentrancy safety and preserve the invariant that the loan amount and fee are recovered or the whole transaction reverts.

== Combining with Capped

Use `max_flash_loan_with_cap` and `flash_loan_with_cap` together in the public lender implementation. The first reports the remaining supply under the cap, and the second checks that limit before calling the borrower.

[source,rust]
----
use openzeppelin_stylus::token::erc20::{
    extensions::{capped::Capped, flash_mint, Erc20FlashMint},
    Erc20,
};

// In IErc3156FlashLender for a token containing `erc20`, `flash_mint`, and
// `capped` fields:
fn max_flash_loan(&self, token: Address) -> U256 {
    self.flash_mint.max_flash_loan_with_cap(
        token,
        &self.erc20,
        &self.capped,
    )
}

fn flash_loan(
    &mut self,
    receiver: Address,
    token: Address,
    value: U256,
    data: Bytes,
) -> Result<bool, flash_mint::Error> {
    self.flash_mint.flash_loan_with_cap(
        receiver,
        token,
        value,
        &data,
        &mut self.erc20,
        &self.capped,
    )
}
----

Do not call the plain `flash_loan` method from a capped lender implementation. Its maximum is limited only by `U256::MAX` and the current total supply.

[[usage]]
== Usage

In order to make https://docs.rs/openzeppelin-stylus/0.4.0/openzeppelin_stylus/token/erc20/extensions/flash_mint/index.html[`ERC-20 Flash Mint`]  methods “external” so that other contracts can call them, you need to add the following code to your contract:

[source,rust]
----
use openzeppelin_stylus::token::erc20::{
    extensions::{flash_mint, Erc20FlashMint, IErc3156FlashLender},
    Erc20, IErc20,
};

#[entrypoint]
#[storage]
struct Erc20FlashMintExample {
    erc20: Erc20,
    flash_mint: Erc20FlashMint,
}

#[public]
#[implements(IErc20<Error = flash_mint::Error>, IErc3156FlashLender<Error = flash_mint::Error>)]
impl Erc20FlashMintExample {}

#[public]
impl IErc3156FlashLender for Erc20FlashMintExample {
    type Error = flash_mint::Error;

    fn max_flash_loan(&self, token: Address) -> U256 {
        self.flash_mint.max_flash_loan(token, &self.erc20)
    }

    fn flash_fee(
        &self,
        token: Address,
        value: U256,
    ) -> Result<U256, Self::Error> {
        self.flash_mint.flash_fee(token, value)
    }

    fn flash_loan(
        &mut self,
        receiver: Address,
        token: Address,
        value: U256,
        data: Bytes,
    ) -> Result<bool, Self::Error> {
        self.flash_mint.flash_loan(
            receiver,
            token,
            value,
            &data,
            &mut self.erc20,
        )
    }
}

#[public]
impl IErc20 for Erc20FlashMintExample {
    type Error = flash_mint::Error;

    fn total_supply(&self) -> U256 {
        self.erc20.total_supply()
    }

    fn balance_of(&self, account: Address) -> U256 {
        self.erc20.balance_of(account)
    }

    fn transfer(
        &mut self,
        to: Address,
        value: U256,
    ) -> Result<bool, Self::Error> {
        Ok(self.erc20.transfer(to, value)?)
    }

    fn allowance(&self, owner: Address, spender: Address) -> U256 {
        self.erc20.allowance(owner, spender)
    }

    fn approve(
        &mut self,
        spender: Address,
        value: U256,
    ) -> Result<bool, Self::Error> {
        Ok(self.erc20.approve(spender, value)?)
    }

    fn transfer_from(
        &mut self,
        from: Address,
        to: Address,
        value: U256,
    ) -> Result<bool, Self::Error> {
        Ok(self.erc20.transfer_from(from, to, value)?)
    }
}
----
