    alloy-primitives/alloy-sol-types 1.5.7 and alloy 1.7.3. Drop motsu, which
    conflicts with alloy 1.x over the ckzg native library. Replace the
    SDK 0.9 global accessors, call paths and public trait markers in the core
    utilities and proxy helpers. The contracts crate does not compile yet; the
    remaining modules are migrated in follow-up commits.
